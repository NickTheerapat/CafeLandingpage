Frontend Development, Responsive Web Design, UX/UI Design และ Conversion Optimization

ผมต้องการให้คุณเป็นผู้ช่วยในการออกแบบและพัฒนาเว็บไซต์ของผม

โปรเจกต์วันนี้:
สร้างเว็บไซต์แบบ Single-Page Landing Page สำหรับร้าน
“2พฤษภา Camping Cafe”

วัตถุประสงค์หลักของเว็บไซต์:

กลุ่มเป้าหมาย:
- ครอบครัว
- กลุ่มเพื่อน
- คู่รัก
- คนที่ต้องการพักผ่อนใกล้ชิดธรรมชาติ
- คนที่ชอบบรรยากาศแคมป์ปิ้ง
- ผู้ที่สนใจกิจกรรมตกปลา

Brand Personality:
- อบอุ่น
- เป็นกันเอง
- ธรรมชาติ
- ชิล
- สนุก
- เหมาะกับครอบครัว
- Outdoor / Camping
- Modern Rustic

หลีกเลี่ยง:
- ดีไซน์ที่ดู Corporate เกินไป
- ความหรูหราจนไม่เข้ากับบรรยากาศร้าน
- UI ที่ซับซ้อน
- สีที่ฉูดฉาดเกินไป
- Animation ที่มากเกินความจำเป็น

==================================================
WORKFLOW สำคัญ
==================================================

ห้ามเริ่มเขียนโค้ดทันที

ให้ทำงานทีละขั้นตอน และต้องถามผมเพื่อขออนุมัติก่อน
เริ่มขั้นตอนถัดไปเสมอ

ขั้นตอนการทำงาน:

STEP 1:
วิเคราะห์ Requirement และสรุปความเข้าใจเกี่ยวกับ
- เป้าหมายเว็บไซต์
- กลุ่มเป้าหมาย
- Brand Direction
- Primary CTA
- Secondary CTA

จากนั้นถามผมว่าต้องการแก้ไขหรือยืนยันหรือไม่

STEP 2:
เสนอ Sitemap / Section Structure ของ Single-Page Landing Page
พร้อมอธิบายเหตุผลด้าน UX ว่าทำไมแต่ละ Section จึงเรียงตามลำดับนั้น

จากนั้นรอการอนุมัติ

STEP 3:
เสนอ UX/UI Direction ประกอบด้วย
- Color Palette
- Typography
- Spacing
- Border Radius
- Button Style
- Card Style
- Icon Style
- Responsive Strategy

จากนั้นรอการอนุมัติ

STEP 4:
เสนอ Wireframe ในรูปแบบข้อความ
สำหรับ Mobile ก่อน แล้วอธิบายการปรับเป็น Tablet และ Desktop

จากนั้นรอการอนุมัติ

STEP 5:
หลังจากได้รับอนุมัติทั้งหมดแล้วเท่านั้น
จึงเริ่มเขียนโค้ด

==================================================
WEBSITE REQUIREMENTS
==================================================

สร้าง Single-Page HTML Landing Page

Product/Service:
ร้านคาเฟ่ “2พฤษภา Camping Cafe”

Brand Style:
Camping Cafe / Nature / Warm / Modern Rustic

Technical Stack:
- Single HTML file
- Inline CSS เท่าที่จำเป็น
- ใช้ Tailwind CSS CDN
- Mobile-first Responsive Design
- Clean และ Semantic HTML
- Accessibility Friendly
- ไม่ใช้ Framework เพิ่มเติม
- สามารถเปิดไฟล์ใน Browser ได้ทันที
- โค้ดต้องมี comments อธิบายแต่ละ Section
- จัดโครงสร้างโค้ดให้อ่านง่ายและแก้ไขง่าย

==================================================
RESPONSIVE REQUIREMENTS
==================================================

ออกแบบแบบ Mobile-first

รองรับอย่างน้อย:
- Mobile: 320px+
- Tablet: 768px+
- Desktop: 1024px+
- Large Desktop: 1280px+

ข้อกำหนด:
- ห้ามเกิด Horizontal Scroll
- ปุ่มและพื้นที่กดต้องเหมาะกับ Mobile
- CTA ต้องมองเห็นชัดเจน
- Form ต้องใช้งานง่ายบนมือถือ
- Layout ต้องปรับตามขนาดหน้าจออย่างเหมาะสม
- Navigation บน Mobile ใช้รูปแบบที่เหมาะสม เช่น Hamburger Menu

==================================================
SECTION REQUIREMENTS
==================================================

1. NAVIGATION
- Logo / ชื่อร้าน
- เมนู Anchor Links
- CTA สำหรับจองโต๊ะ
- Responsive Mobile Navigation

2. HERO SECTION
Background:
สีโทนเขียว + เขียวพาสเทล

Hero Image:
ใช้ Placeholder Image ตัวอย่างในธีม
Camping Cafe / Nature / Outdoor
และใส่ comment ระบุตำแหน่งที่สามารถเปลี่ยนเป็นรูปจริงได้

Tagline:
“ปิ้งไป ชิลไป ในบรรยากาศแคมป์”

Primary CTA:
“จองโต๊ะ”

Secondary CTA:
“ดูเมนู” หรือ “ดูบรรยากาศ”

Hero ต้องสื่อสารได้ชัดเจนภายในไม่กี่วินาทีว่า:
- ร้านคืออะไร
- มีประสบการณ์แบบไหน
- ผู้ใช้ควรทำอะไรต่อ

3. KEY FEATURES

Feature 1:
ชื่อ: พื้นที่พักผ่อนสำหรับทุกคน
รายละเอียด:
พื้นที่นั่งพักผ่อนและทำงาน พร้อมบรรยากาศครอบครัวที่อบอุ่นและเป็นกันเอง

Feature 2:
ชื่อ: แคมป์ปิ้งสุดชิล ใกล้ชิดธรรมชาติ
รายละเอียด:
นั่งกิน นั่งคุย สูดอากาศดีๆ พร้อมวิวและบรรยากาศที่เหมาะกับการพักผ่อน

Feature 3:
ชื่อ: บ่อตกปลา
รายละเอียด:
บ่อตกปลาสำหรับกิจกรรมและช่วงเวลาแห่งความสุขของครอบครัว

แต่ละ Feature:
- มี Icon หรือ Illustration
- อ่านง่ายบนมือถือ
- มีลำดับข้อมูลที่ชัดเจน

4. EXPERIENCE / MENU PREVIEW
แสดงตัวอย่างประสบการณ์ของร้าน เช่น
- เครื่องดื่ม
- อาหาร
- ปิ้งย่าง
- กิจกรรม
- บรรยากาศธรรมชาติ

ใช้ Placeholder Content ได้
แต่ต้องออกแบบให้เปลี่ยนเป็นข้อมูลจริงภายหลังได้ง่าย

5. SOCIAL PROOF
ประกอบด้วย:
- Testimonials Placeholder
- Metrics Placeholder
- Trust Badges Placeholder

ออกแบบให้ดูน่าเชื่อถือ แต่ไม่ใช้ข้อมูลจริงที่แต่งขึ้น
ให้ระบุ Placeholder อย่างชัดเจน

6. LOCATION / CONTACT
เตรียมพื้นที่สำหรับ:
- เวลาเปิด-ปิด
- ที่ตั้ง
- แผนที่
- เบอร์โทรศัพท์
- LINE
- Facebook
- Instagram

หากยังไม่มีข้อมูลจริง ให้ใช้ Placeholder ที่ชัดเจน

7. CALL-TO-ACTION / RESERVATION
มี Secondary CTA ที่ชัดเจน

สร้าง Form สำหรับติดต่อหรือจองโต๊ะ เช่น:
- ชื่อ
- เบอร์โทรศัพท์
- จำนวนคน
- วันที่ต้องการ
- เวลา
- ข้อความเพิ่มเติม

หมายเหตุ:
Form เป็น Frontend UI เท่านั้น
ไม่ต้องเชื่อมต่อ Backend เว้นแต่ผมจะสั่งเพิ่มเติม

มี Privacy Note ใต้ Form

8. FOOTER
ประกอบด้วย:
- Quick Links
- Social Media Icons
- Contact Information
- Copyright
- Placeholder สำหรับข้อมูลร้านที่ยังไม่มี

==================================================
COLOR SYSTEM
==================================================

ใช้สีจาก Brand Direction

Primary:
สีเขียวธรรมชาติ

Secondary:
สีเขียวพาสเทล

Accent:
สีที่โดดเด่นสำหรับ CTA แต่ยังเข้ากับธีม Camping Cafe

Background:
สีขาวและสีธรรมชาติที่ช่วยให้เว็บไซต์ดูอบอุ่น

Text:
ต้องมี Contrast ที่อ่านง่ายและคำนึงถึง Accessibility

ก่อนเขียนโค้ด:
ให้เสนอชื่อสีและค่า HEX/RGB ที่แนะนำก่อน
และรอการอนุมัติ

==================================================
TYPOGRAPHY
==================================================

Headings:
เลือกฟอนต์ Google Fonts ที่เหมาะกับภาษาไทยและอังกฤษ

Body:
ใช้ฟอนต์ที่อ่านง่าย รองรับภาษาไทยได้ดี

ต้องพิจารณา:
- Mobile Readability
- Line Height
- Font Weight
- Responsive Typography

ก่อนเขียนโค้ด:
ให้เสนอคู่ฟอนต์ที่เหมาะสม 2-3 ตัวเลือก
พร้อมอธิบายสั้นๆ และรอการอนุมัติ

==================================================
ACCESSIBILITY
==================================================

เว็บไซต์ต้อง:
- ใช้ Semantic HTML
- มี alt text สำหรับรูปภาพ
- มี label สำหรับ Form
- รองรับ Keyboard Navigation
- มีสีและ Contrast ที่อ่านง่าย
- ไม่พึ่งพาสีเพียงอย่างเดียวในการสื่อสารข้อมูล
- ใช้ heading hierarchy ที่ถูกต้อง

==================================================
CODE QUALITY
==================================================

เมื่อเริ่มเขียนโค้ด:
- ส่งโค้ด HTML ไฟล์เดียว
- พร้อมเปิดใน Browser ได้ทันที
- ใช้ Tailwind CSS CDN
- มี comments แบ่งแต่ละ Section
- ไม่เขียนโค้ดซ้ำโดยไม่จำเป็น
- จัดโครงสร้างให้ง่ายต่อการแก้ไขในอนาคต
- ใช้ Placeholder ที่ค้นหาและเปลี่ยนได้ง่าย
- ตรวจสอบ Responsive Layout ก่อนส่ง

สำคัญที่สุด:
ในแต่ละ STEP ต้องถามและรอการอนุมัติจากผมก่อน
ห้ามข้ามขั้นตอนและห้ามเริ่มเขียนโค้ดจนกว่าจะได้รับอนุมัติครบตาม Workflow

เริ่มต้นที่ STEP 1 เท่านั้น
